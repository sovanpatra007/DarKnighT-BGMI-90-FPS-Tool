# DarKnighT BGMI 90 FPS Analyzer
Native Android starter project.

Features:
- Device and Android version detection
- Display refresh-rate detection
- RAM diagnostics
- Read-only root availability check
- Safe BGMI optimization guidance

This app does not modify BGMI files, bypass game whitelists, spoof device identity, or guarantee 90 FPS.
Build with JDK 17, Android SDK 35, Android Gradle Plugin 8.7.3, Kotlin 2.0.21 and Gradle 8.9.
